# Geschichte bis 1500 – Zeitstrahl

Eigenständiges Zeitstrahl-Spiel mit Datierungen aus der Lernumgebung «Geschichte bis 1500».

## Funktionen

- 23 historische Datierungen
- drei Niveaus mit vier, fünf oder sechs Ereignissen pro Runde
- modulübergreifende Runden über 3, 6 oder alle 13 Module
- Bedienung mit Maus, Tastatur und Touch
- vollständige Lösung nach jeder Prüfung
- lokaler Lernstand mit Backup und Wiederherstellung

## Entwicklung

```sh
npm test
npm run build
```
